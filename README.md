📊 Vrinda Store Data Analysis (Excel Project)

📌 Project Overview

This project focuses on analyzing sales and customer data of Vrinda Store using Microsoft Excel to derive meaningful business insights.
The objective is to understand sales performance, customer behavior, and channel effectiveness to support data-driven decision-making.

🎯 Objectives

Analyze overall sales performance

Identify top-performing products and categories

Understand customer demographics and buying patterns

Compare sales across different channels

Provide actionable insights using dashboards and visualizations

🗂️ Dataset Description

The dataset contains store transaction data with the following key attributes:

Order ID

Date (Month-wise sales)

Customer Gender

Age Group

Product Category

Sales Channel (Online / Offline / Platforms)

Order Status

Quantity Sold

Revenue

(Data is assumed to be structured and cleaned for analysis purposes.)

🛠️ Tools & Techniques Used

Microsoft Excel

Pivot Tables

Pivot Charts

Slicers

Conditional Formatting

Data Cleaning & Transformation

Excel Dashboards for interactive analysis

📈 Key Analysis Performed

Monthly Sales Trend Analysis

Sales by Gender & Age Group

Category-wise Sales Performance

Channel-wise Revenue Contribution

Order Status Analysis (Delivered, Returned, Cancelled, etc.)

📊 Dashboard Highlights

The Excel dashboard provides:

Interactive slicers for Month, Category, Channel, and Gender

Visual insights using:

Bar Charts

Line Charts

Pie Charts

Quick identification of:

Best-selling categories

High-value customer segments

Most effective sales channels

🔍 Key Insights

Women customers contribute a higher percentage of total sales

Adult age group dominates overall purchases

Certain categories consistently outperform others

Online channels generate higher revenue compared to offline sales

Seasonal trends significantly impact monthly sales

(Insights may vary depending on slicer selection.)
